# Step by step guide how to create new repo:
1. Create new directory on your local machine with specific name.
2. Init directory with `git init` command to mark directory as git repo catalog.
4. Create git remote repository and run `git add remote` to connect with local repo.
5. Add needed files using `git add .` command and commit with `git commit`.
6. Push it to remote repo - `git push`.
7. After steps above feel free to create branches from main.
